\page licenseFile.md License

There are two types of license for Meishe SDK, SDK license and package license. The SDK license used to verify SDK license, and package license used to install asset package.
Each asset package need one package license with the same uuid. The SDK license and package license must be used together, either both or neither.
Meishe SDK would not render if license not be used, except localhost development environment.
