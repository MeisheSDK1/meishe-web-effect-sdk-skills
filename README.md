# meishe-web-effect-sdk-skills

> Modular beauty and visual-effect skills for browser camera, live streaming, and video apps.

## Overview

Meishe Web Effect SDK Skills provides composable, AI-driven beauty and effect components for Web applications. Add skin smoothing, face reshaping, virtual makeup, filters, and AR stickers to camera, live streaming, or video workflows without rebuilding a visual-effects stack.

## Key Skills

- **Beauty** — skin smoothing and facial enhancement
- **Face Reshaping** — natural face adjustment
- **Virtual Makeup** — real-time makeup effects
- **Filters** — style presets and color looks
- **AR Stickers** — interactive visual overlays

## Why These Skills

- Modular integration—use only the effects you need
- Real-time, AI-driven visual processing for Web
- Built for browser camera and video pipelines
- Faster launch for beauty-camera and social video features

## Typical Use Cases

Beauty camera · live streaming · short video · social web apps · video conferencing · e-commerce visual experiences

## Getting Started

1. Choose the effect skills for your scenario.
2. Integrate the SDK into your Web camera/video pipeline.
3. Configure beauty, makeup, filters, or AR assets.
4. Validate performance across target browsers and devices.
